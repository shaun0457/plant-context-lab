30 秒上手
用你自己的 LLM 操作

這會在你自己的電腦上跑一份模擬，只會改到你自己那一份。接著打開 127.0.0.1:8787，就能看到你的 LLM 做的每個呼叫。需要電腦上裝有 Node.js 22.18 以上。

在終端機執行一次： 
claude mcp add plant-context-lab -- npx -y github:shaun0457/plant-context-lab#v0.4.0
加進 ~/.codex/config.toml： 
[mcp_servers.plant-context-lab]
command = "npx"
args = ["-y", "github:shaun0457/plant-context-lab#v0.4.0", "--scenario", "idv4-step5"]
startup_timeout_sec = 60
加進你的工具的 MCP 設定（stdio）： 
{
  "mcpServers": {
    "plant-context-lab": {
      "command": "npx",
      "args": ["-y", "github:shaun0457/plant-context-lab#v0.4.0", "--scenario", "idv4-step5"]
    }
  }
}
Windows 上如果找不到 npx：把 "command" 改成 "cmd"，並在 "args" 最前面加上 "/c", "npx"。
